# 🎃 Witch’s Potion Match — ハロウィンのマッチ3パズル

**月明かりを少々、お菓子をひとつかみ。もう一度、きれいな連鎖を。** 材料を入れ替え、レシピを満たし、ろうそくを灯して 12 種類の魔法薬を作ります。Midnight Candy Club の一作で、[BlockBlasty](https://blockblasty.top/) のハロウィン企画として制作したブラウザーパズルです。

**[今すぐ遊ぶ](https://halloween-potion-match.crazy3d.org/)** · [ハロウィンゲーム集](https://github.com/AshinTop/halloween-games) · [埋め込みガイド](EMBEDDING.md) · [設計ノート](DESIGN.md)

## 大鍋にはどんな魔法が？👻

- **再現可能な 12 種類のレシピ**。6×6 の盤面に、かぼちゃキャンディー、月明かり、コウモリの実、ミント、星くずが並びます。
- 隣接交換、同時消去、落下、連鎖を備えています。すべてのレシピに、通常交換だけでクリアできる検証があります。
- 消す場所も大切になるろうそくの目標と、各レシピで一度使える十字消去の Moon Spark。
- 光を集める材料、色の粒、レシピへ飛ぶ図柄、正しい位置からの落下と小さな着地の弾み。
- ヒント、レシピ選択、何度でもやり直し、ローカル記録と星、任意の音、動きを減らす設定。

## 魔法薬の作り方

まず必要な材料の数を確認しましょう。隣り合う 2 マスを入れ替え、同じ材料を縦か横に 3 つ以上そろえます。斜めの交換や、行の端から反対側への交換はできません。そろわない交換では手数を消費しません。

有効な交換は 1 手として数えます。その後に何回連鎖しても追加の手数はかからず、落下後の消去も材料の目標に加算されます。連鎖が深くなるほど得点が増えるため、小さな交換から大きな成果につながることもあります。

ろうそくがあるレシピでは、そのマス、または上下左右に直接隣接するマスの材料を消すと点灯します。クリアには、**必要な材料すべてと、ろうそくすべて**をそろえてください。材料だけ集めてもまだ完成ではありません。

**Moon Spark** を押してからマスを選ぶと、その行と列をまとめて消せます。最初の消去は重複を除く 11 マスで、その後の連鎖は通常どおり処理されます。各レシピで一度だけ使え、手数は減りません。残り 0 手でも、未使用なら最後のチャンスとして使えます。

時間制限はありません。残り 8 手以上で完成すると星 3 個、3 手以上なら 2 個、それ以外の成功は 1 個です。ヒントは現在の目標に役立つ合法な交換を選びますが、その後のすべての判断が成功するという保証ではありません。

## 操作

| 操作 | マウス・タッチ | キーボード |
|---|---|---|
| 選択と交換 | 隣の 2 マスをタップ、またはスワイプ | 矢印で移動、Enter / Space で選択 |
| Moon Spark | ボタンの後にマスを選択 | Tab でボタンへ移動して実行 |
| ヒント | Hint ボタン | H |
| 選択解除 | 選択中のマスをもう一度タップ | Escape |
| やり直し・レシピ変更 | ボタン・選択メニュー | Tab で操作 |

次の交換は連鎖が落ち着いてから行います。演出中も、やり直しやレシピ変更は可能です。古い演出は取り消され、新しい盤面に古い得点や結果を反映しません。

## 記録と共有

同じレシピで同じ操作をすると、同じ結果になります。最高得点、星、言語、音の設定はブラウザーに保存します。再読み込みではレシピを最初から始め、途中の盤面は復元しません。[レシピ 8 のリンク](https://halloween-potion-match.crazy3d.org/#recipe=8) で共有するのは開始配置で、プレイの再生データではありません。

## よくある質問

**Moon Spark がなくてもクリアできますか？** はい。12 種類すべてで、通常の交換によるクリアを検証しています。

**盤面が並び替わるのはなぜ？** 合法な交換がなくなると、現在の材料を並び替えます。分布が極端な場合は補充が必要になることもありますが、目標、得点、残り手数は保持します。

**演出が止まったら？** キャンセルと待機時間の上限を備えています。効果が失敗したり時間軸が進まなくなっても、計算済みの合法な結果を確定し、操作を再開できるようにします。

## 自分のサイトに埋め込む

```html
<iframe src="https://halloween-potion-match.crazy3d.org/"
  title="Witch’s Potion Match"
  style="display:block;width:100%;height:654px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

基準となる表示領域は、デスクトップ 1160×654、縦向き 390×650 / 390×794、横向き 844×340 です。iframe 内の実際の領域を使って配置し、すべての実機端末での動作を保証するものではありません。

公開版は、この GitHub リポジトリと連携して Cloudflare にデプロイされています。iframe に高さを指定し、親サイトのツールバー用の領域も確保してください。全画面ボタンは親サイト側で用意できます。詳細は [EMBEDDING.md](EMBEDDING.md) を参照してください。

## ローカルで実行・確認する

```sh
python3 -m http.server 4173
```

リポジトリのルートでサーバーを起動し、[http://localhost:4173/](http://localhost:4173/) を開きます。静的なゲームなので、ビルドや依存パッケージのインストールは不要です。`file://` では ES モジュールが読み込めない場合があるため、HTTP(S) を使用してください。テストには Node.js が必要です。

```sh
npm test
```

**24 件のテスト**で、ルール、全レシピのクリア、古いポインター入力、同時操作、落下経路、連鎖ごとの数値、各段階のキャンセル、演出失敗と停止した時間軸からの復帰を確認します。

ゲームのソースはアカウント、外部 API、広告 SDK、外部素材 CDN を必要としません。記録はブラウザー内に保存され、クラウド同期はありません。Cloudflare が独自のホスティング用スクリプトやリクエストログを追加する場合があります。任意の合成音声はブラウザーの再生許可に従います。
